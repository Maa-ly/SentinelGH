# SentinelGH weekly submissions

Each week has its own folder and ZIP archive:

- week8: log reader, detection functions, menu, alert file and problem analysis.
- week9: object-based version, class diagram and weak-password scores.
- week10: inheritance, four detector subclasses, separate modules and module notes.
- week11: data cleaning, summary CSVs, four charts and a draft daily report.

Open the README in the relevant folder for run instructions. All weekly programs read the shared CSVs in `logs/`. Extract each week folder
beside that folder; the weekly archives do not duplicate the input data. TeamNo in ZIP filenames
is a placeholder for your team number. Presentation notes are included for every week.
The original script and documents are preserved in their original locations.
